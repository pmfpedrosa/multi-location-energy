# Reusable Location Energy cards

Adds the Location Energy custom card to the dashboard card picker. Choose a
location and a native Energy card, including distribution, charts, totals, flow
diagrams, gauges and date selection. Put Frestia_1 and Frestia_2 side by side on
one dashboard. Shared date groups synchronize periods and comparisons without
sharing meters or preferences; independent groups keep separate dates.

The frontend resource registers automatically. Reload the browser after the
update and restart. Setup and ready-to-use YAML: docs/LOCATION-CARDS.md.

This prerelease contains no generators. Existing panel behavior is unchanged;
the previously observed blank Configure view remains a separate issue.
Local isolation, card lifecycle and browser boundary tests pass. Live acceptance
of reusable cards is pending; no complete native feature certification is claimed.
