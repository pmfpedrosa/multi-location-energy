# Native dashboard and separate generator settings

Keeps the separate Generators menu for adding and editing generator meters. Dashboard opens the native Energy panel, with distinct generator production in the extended cards, charts and totals. Generator settings are no longer embedded in Configure. Locations without generators use the unchanged native dashboard path.

Includes the atomic dashboard initialization and stable translation identity fixes from beta 2. Local isolation, menu navigation, native-card fixture tests and electricity/fuel calculations pass. Live verification of both locations is pending; this is not a stable release.
